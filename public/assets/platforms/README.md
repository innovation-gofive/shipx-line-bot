# Platform icons

PNG copies of the official site favicons, downloaded 2026-11-23 and converted without changing their content for LINE Flex compatibility.

- Shopee: https://shopee.co.th/favicon.ico
- Lazada: https://www.lazada.co.th/favicon.ico
- TikTok: https://www.tiktok.com/favicon.ico

In production, Flex Messages reference these files through the application's HTTPS APP_URL.
